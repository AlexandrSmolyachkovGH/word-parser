# Анализ ключевых слов

Веб-приложение для анализа ключевых фраз из Яндекс Директ и Google Ads.

## Возможности

- Вставка фраз из Яндекс Директ / Google Ads
- Разбивка на слова с подсчётом частотности
- Сортировка по колонкам (возрастание/убывание)
- Фильтрация фраз по клику на слово
- Маркеры для слов (без маркера, минусующее, фильтрующее, другое)

## Cборка и локальный запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/AlexandrSmolyachkovGH/word-parser.git
   cd ./word-parser
   ```

2. Создайте .env файл:
    ```bash
   cp .env.example .env
   ```
   В качестве ключа VITE_OPENROUTER_API_KEY установите ваш API_KEY от OPENROUTER.
3. Запустите проект через Docker:
    ```bash
   docker compose up -d --build
   ```
4. Перейдите по ссылке `http://localhost:8080/`

## Технологии
